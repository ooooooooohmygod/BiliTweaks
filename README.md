# bili-noads

哔哩哔哩国内版去广告模块。

## 功能

1. 去开屏广告
2. 去暂停页广告
3. 去结束页广告
4. 去更新检测

## 界面

内置 Material 3 沉浸式界面，顶栏贴合系统状态栏；首页为功能开关列表（修改后对后续触发立即生效）。

## 开关

| 开关 | 说明 |
| --- | --- |
| 去开屏广告 | 关闭后恢复启动开屏广告 |
| 去暂停页广告 | 关闭后恢复暂停页广告 |
| 去结束页广告 | 关闭后恢复结束页广告 |
| 去更新检测 | 关闭后恢复更新检查与安装提示 |

全部开关默认开启；开屏与更新检测相关开关在哔哩哔哩下次启动时最稳妥。
