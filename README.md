# bili-noads

哔哩哔哩去广告（开屏 / 暂停页 / 结束页）与去更新检测的 LSPosed 模块。

## 功能

| 功能 | 说明 |
| --- | --- |
| 去开屏广告 | 订单、内容、页面工厂三处返回值置空（保留原副作用） |
| 去暂停页广告 | 暂停页总开关恒 false |
| 去结束页广告 | 解码入口与兜底入口恒 false |
| 去更新检测 | 启动检查 / 手动检查 / 缓存强更 / 安装提示共 4 处禁用 |
